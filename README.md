### Mateusz Jastrzębski

MSc Quantitative Finance student at the University of Warsaw. Before that: a CS engineering degree at PJATK and a year as a developer (Java/Spring, Angular, Python). I work on machine learning for crypto markets, options and volatility, and the data tooling around both.

**Selected work**

- [**btc-ml-pipeline**](https://github.com/MateuszJastrzebski21/btc-ml-pipeline) - Can classical ML time Bitcoin? Walk-forward study of 5-day BTC direction with calibration, block-bootstrap CIs, a cost-aware backtest against buy-and-hold, and a post-thesis audit of my own results. B.Sc. thesis.
- [**job-market-intelligence**](https://github.com/MateuszJastrzebski21/job-market-intelligence) - LLM pipeline that ingests job postings, extracts structured fields and measures extraction and retrieval quality against hand-labelled sets. Postgres + pgvector, CI.
- [**TrackmaniaRL**](https://github.com/TrackmaniaRL/TrackmaniaRL) - contributor to an open-source reinforcement learning library for Trackmania (training-loop fix for stale rollouts).
- [**Implied-Volatility-Surface**](https://github.com/MateuszJastrzebski21/Implied-Volatility-Surface) - implied volatility surface from listed option chains via Black-Scholes inversion.
